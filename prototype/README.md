# HTML Combat Prototype

`riftbound-control-lab.html` is a single-file browser prototype used to settle the combat design (controls, gems, loadout, fusion) before building it in Godot. Open it in any browser; on a phone it plays in portrait with touch.

- It is the **behavioral reference** for milestones M1–M6.
- Its numbers use a **360-wide** world. `docs/combat-spec.md` holds the converted **270-wide** values (×0.75). When the two disagree, the spec wins.
- Pause menu (**II**) has debug buttons: +10 baby balls, +1 level, all balls Lv3, +1 prism, fill ultimate.
- Not shipped with the game.
